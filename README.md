# roguelike_2d

In this project, I am building a turn-based roguelike with procedural level generation, enemies, and resource management. The project will also be extended with audio, visual effects, smooth movement, and object pooling.

## Features

- **Controls**
  - Movement is controlled using the keyboard arrow keys.

- **Player**
  - The main character includes both idle and walking animations.

- **Enemies**
  - Two different enemy types are implemented:
    - **Zombie**
      - Chases the player when they enter its detection range.
    - **Slime**
      - Moves randomly in a direction.
      - Explodes and deals damage if it moves into the same cell as the player.

- **Game Systems**
  - Procedural level generation.
  - Turn-based movement and interactions.
  - Resource management mechanics.

- **UI**
  - Main menu implemented.
  - Pause menu available during gameplay.
